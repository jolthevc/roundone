# ROUND ONE

ROUND ONE is a daily spoken-word audio ritual built to change the listener's state.

The flagship creative model is:

**Story -> realization -> fire.**

A Round takes the listener somewhere worth going, shows them something true, lets the truth create pressure, then returns them to the world with more agency, urgency, and life.

## Brand

- Brand: ROUND ONE
- Working handle: @justroundone
- Core phrase: Just round one.
- Canonical product: audio
- Typical runtime: 5 to 7 minutes
- Content unit: a Round

## Repository purpose

This repository is the creative source of truth for ROUND ONE and its adjacent creative properties.

The ROUND ONE flagship remains centered on proving excellent creative work before building unnecessary infrastructure.

## Doctor Goodenough

Doctor Goodenough is a distinct social-facing literary property inside the broader ROUND ONE repository.

It is **not** a shortened Round, a social derivative of a Round, or a generic poetry account.

Doctor Goodenough writes about the interior life of men with the present as its center of gravity: work, money, dating, sex, friendship, ambition, status, competition, the body, joy, embarrassment, responsibility, love, success, failure, and the private standards men keep for themselves. Family, memory, childhood, aging, and the future are available lenses rather than the default subject.

Enoughness is the recurring emotional question beneath the work, but most pieces should never say the word.

Doctor Goodenough has its own canon, prompt contracts, examples, production standards, and context manifest under `doctor-goodenough/`.

**Nothing in root `docs/`, `prompts/`, or `system/` applies to Doctor Goodenough unless a Doctor Goodenough file explicitly says otherwise.**

Start with:
- `doctor-goodenough/README.md`
- `doctor-goodenough/manifest.yaml`
- `doctor-goodenough/canon/`

## Current status

The ROUND ONE flagship canon is established and continues to evolve through finished work.

Doctor Goodenough is entering a writing-workflow calibration phase. Its immediate system is deliberately small: GitHub for canon, Google Sheets for state, Google Drive for assets, n8n for orchestration, and a simple HTML control surface. Media production and autonomous publishing come only after the literary pipeline is consistently producing work worth publishing.
