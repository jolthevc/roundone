# 08 - Visual Standard

## Role of the visual

The visual is packaging, not the product.

A listener should lose nothing by locking the phone.

The image should make the Round feel:
- authored
- premium
- serious
- distinctive
- emotionally grounded

## Canonical format

Primary orientation:
**9:16 vertical**

The image should work naturally on a phone screen.

## Core composition

The default ROUND ONE visual system is:

**one symbolic object in darkness**

Characteristics:
- one clear object
- lower-center placement
- large amount of negative space
- near-black surrounding field
- soft local illumination
- restrained color
- painterly fine-art treatment

The object should be large enough to read immediately but small enough to feel isolated.

## Why one object

A single object:
- anchors the story
- avoids over-illustration
- creates a recognizable system
- gives each Round identity
- allows the listener's imagination to create the rest of the scene

We are not producing literal storyboards.

## Preferred style

Dark fine-art editorial.

The rendering should sit between:
- painting
- charcoal
- monotype print
- mixed media
- cinematic editorial art

Not:
- hyperreal photography
- cartoon
- anime
- glossy CGI
- fantasy concept art
- obvious AI surrealism

The image should feel authored rather than generated.

## Texture

Use:
- subtle paper grain
- soft charcoal texture
- slight painterly imperfection
- restrained analog noise
- occasional ink-like softness

Avoid:
- heavy scratches
- distressed poster borders
- excessive concrete grit
- punk-zine grunge
- visual noise for its own sake

The target is:

**dark fine-art print**

not:

**grunge album cover**

## Lighting

The object should emerge from darkness.

Preferred:
- soft local glow
- diffuse directional light
- gentle falloff
- muted contrast

Avoid:
- explicit beam from heaven
- theatrical stage spotlight
- rim-light spectacle
- blockbuster poster lighting

## Palette

Default:
- black
- charcoal
- graphite
- deep muted navy
- desaturated gray

Allow one restrained accent tied to the object:
- burgundy
- rust
- dull amber
- cold blue
- muted green

Avoid bright saturation.

## Object selection

The object should:
- be instantly legible
- carry symbolic weight
- connect naturally to the story
- remain visually simple
- avoid motivational cliche

Examples:
- rose through concrete
- split stone
- hammer
- match
- door
- chair
- worn shoe
- key
- stopwatch
- rope
- chain link
- bell
- candle
- empty glass
- worn glove

## No baked typography

Do not generate the title inside the artwork.

Typography belongs in the product layer so:
- it stays consistent
- it remains editable
- it stays crisp
- artwork can be reused

## Master prompt

Create a dark, minimalist, premium 9:16 cover-style image for a spoken-word audio experience. The composition should feature one single central symbolic object: [OBJECT]. Place it low-center in the frame, surrounded by a vast amount of near-black negative space. The object should feel isolated, emotionally heavy, and iconic.

Style the image as a painted fine-art editorial piece, not photorealistic and not cartoonish. It should feel like a mix of dark mixed-media painting, charcoal, monotype print, and cinematic poster art. Use soft analog texture, subtle grain, slight painterly imperfections, and restrained distressed texture, but keep it premium and not overly grungy.

Lighting should be soft and local, gently illuminating the object and the immediate ground around it, without a dramatic spotlight beam. The object should emerge from darkness rather than be brightly lit. The palette should be mostly black, charcoal, graphite, and deep muted tones, with only very restrained accent color if appropriate to the object.

The background should be a near-black void with faint haze, smoky gradients, and soft textural depth. The image should feel ominous, introspective, refined, symbolic, and emotionally powerful. It should look like elegant album-cover art for a dark cinematic audio piece.

No people. No text. No extra objects. No scenery. No bright colors. No glossy realism. No fantasy elements. No motivational-poster aesthetic. Keep it simple, symbolic, and visually striking.

## Style test

The visual language is proven only when the same system works across very different objects.

A rose, split stone, match, chair, and door should all look like the same brand.

## Motion

Motion is optional.

If used:
- extremely subtle
- slow
- atmospheric
- no narrative sync
- no object transformation
- no dramatic camera move

Possible motion:
- gentle haze
- nearly imperceptible light shift
- tiny drifting dust
- soft grain
- micro push

The still must work perfectly without motion.

## Visual rejection criteria

Reject if:
- it looks like a generic AI motivational poster
- the object is hyperreal
- the image is too grandiose
- there are too many objects
- the scene illustrates the entire narrative
- the grunge overwhelms the elegance
- lighting becomes theatrical
- the symbolism is cliche
- the image requires explanation
