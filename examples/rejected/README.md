# Rejected Examples

This directory will eventually contain a small curated set of useful failures.

Do not archive every bad draft.

Add an example only when it teaches a recurring failure mode such as:
- generic motivation
- overexplained metaphor
- pseudo-philosophy
- weak opening
- weak final act
- unearned profanity
- fake intensity
- soundtrack too active
- visual too literal
- visual too grungy

Each rejected example should include a short explanation of why it failed and how to avoid repeating the mistake.
