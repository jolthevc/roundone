# Gold Standards

This directory is intentionally empty.

ROUND ONE does not yet have a finished piece that has earned canonical gold-standard status.

Do not populate this directory with drafts merely to provide examples.

A future gold-standard Round should include:
- concept
- research where needed
- treatment
- final editorial script
- performance script
- persona
- music choice
- visual prompt
- final cover
- final audio master
- metadata
- QC notes
- short explanation of why it represents the standard

The first gold standards should be selected only after complete end-to-end production and human listening.
