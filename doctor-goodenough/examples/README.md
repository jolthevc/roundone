# Examples

Examples teach taste. They do not create new rules.

## Calibration

`calibration/` contains pieces James would publish unchanged. Start small. Quality matters more than count. The drafting model receives only the title and body, never the metadata or notes.

## Near miss

`near-miss/` contains writing with real life in it that still misses Doctor Goodenough in a useful way. The editor may see the piece and the short failure note. The drafter never sees it.

## Rejected

`rejected/` contains clear failures worth remembering. The editor may see these sparingly. The drafter never sees them.

A calibration piece may later be marked as especially important in its metadata. There is no separate "gold" folder.
