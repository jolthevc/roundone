# Performance Direction Prompt

## Required context

Read:
- docs/05_VOICE_PERSONAS.md
- docs/06_PERFORMANCE_STANDARD.md

## Input

An approved editorial script.

## Job

1. choose the primary voice persona
2. explain the choice briefly
3. convert the script into a performance-directed version

Use sparse direction tags such as:
- [quiet]
- [closer]
- [slower]
- [pause 1s]
- [hold]
- [harder]
- [building]
- [raised voice]
- [whisper]

## Rules

- do not tag every line
- preserve the words unless a tiny punctuation change improves speech
- narrator creates the emotional arc
- save dynamic range for the end
- shouting is rare
- pauses should feel human

## Output

1. persona
2. performance trajectory
3. performance-directed script
