# Visual Generation Prompt

## Required context

Read:
- docs/08_VISUAL_STANDARD.md

## Input

Provide:
- Round title
- core realization
- one proposed symbolic object

## Job

Create one production-ready 9:16 image-generation prompt.

## Required visual behavior

- one symbolic object
- lower-center
- huge black negative space
- painted fine-art editorial style
- charcoal / monotype / mixed-media influence
- soft local light
- restrained accent color
- not photoreal
- not cartoon
- not overly grungy
- no baked text
- no people unless explicitly approved

## Output

Return:
1. object
2. one-sentence rationale
3. final single image prompt

Do not generate multiple concepts unless asked.
