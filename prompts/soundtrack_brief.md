# Soundtrack Brief Prompt

## Required context

Read:
- docs/07_MUSIC_STANDARD.md

## Input

Provide:
- Round title
- core realization
- emotional register
- intensity
- narrator persona

## Job

Choose the best existing soundtrack family or state that a new bed is justified.

The default is reuse.

## Selection principle

The music establishes an emotional state.

It must not narrate the story.

## Output

1. recommended family
2. reason
3. risks
4. mix note

If generating a new bed, produce a concise music-generation or composer brief emphasizing:
- steady state
- no crescendo
- no climax
- no heroic resolution
- narrator remains dominant
