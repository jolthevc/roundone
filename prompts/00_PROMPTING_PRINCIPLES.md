# Prompting Principles

The prompts in this directory are execution briefs.

They do not replace the creative canon.

Before running a prompt, provide the relevant docs as context.

## Hierarchy

If a prompt conflicts with the canon:
- the canon wins

If a one-off instruction conflicts with the approved concept:
- flag the conflict

## Prompt behavior

Prefer:
- one clearly defined job
- explicit inputs
- explicit output structure
- reference to canon
- self-critique before final output

Avoid:
- one mega-prompt that ideates, writes, performs, scores, and approves everything
- asking a model to judge its own work without a separate review pass
- vague requests for something inspiring

## Creative pipeline

Recommended sequence:

1. ideation
2. treatment
3. research where factual
4. script
5. editorial review
6. revision
7. fire pass
8. performance direction
9. voice render
10. music assignment
11. visual generation
12. final QC

The workflow implementation comes later.
