# Script Generation Prompt

## Required context

Read:
- docs/00_BRAND_NORTH_STAR.md
- docs/02_NARRATIVE_STANDARD.md
- docs/04_WRITING_AND_TONE.md

Also read:
- the approved concept
- the approved treatment
- research notes where factual

## Job

Write the editorial script for one Round.

Target:
- 5 to 7 minutes
- spoken language
- one narrative
- one realization
- one coherent emotional arc

## Requirements

- begin concretely
- do not announce the lesson early
- make the story move
- let the listener infer before explaining
- include at least one memorable line
- earn direct address
- keep profanity purposeful
- make the final 60 to 90 seconds materially stronger
- use a callback when natural
- end with a line worth silence

## Prohibitions

Do not:
- fabricate facts
- imitate a famous speaker
- use motivational cliches
- overexplain metaphors
- add random philosophical language
- end with generic you got this encouragement
- humiliate the listener

## Output

Return only:
1. title
2. clean editorial script
3. one-sentence statement of the core realization
