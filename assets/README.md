# Assets

This directory is reserved for lightweight approved creative assets and manifests.

Expected categories later:
- brand
- approved visuals
- voice references
- soundtrack references
- soundtrack masters
- gold-standard examples

Large binary masters may eventually live in dedicated object storage rather than GitHub.

When that happens, this repository should retain:
- stable asset IDs
- metadata
- licensing notes
- source references
- approved usage
- storage locations

Do not add unlicensed third-party music or copyrighted reference media to the repository.
